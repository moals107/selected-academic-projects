# Selected Academic Projects

A small collection of selected projects completed during my **B.Sc. Computer Science at Heinrich Heine University Düsseldorf**.

These projects complement the larger projects highlighted on my GitHub profile and show additional work in mathematical visualization, digital innovation and academic research.

## Projects

### [Koch Snowflake — Mathematical Visualization](./koch-snowflake/)

**Python · Jupyter · NumPy · Matplotlib**

Implementation and visualization of the iterative construction of the Koch snowflake, including analysis of perimeter growth and area convergence across multiple iterations.

### [JupiGuide — Digital Innovation Concept](./jupiguide/)

**Product Concept · AI/AR · MVP · User Experience**

Team-based concept for a personalized city-guide application combining route recommendations, historical context, interactive maps and location-based content.

### [Brain-Machine Interfaces](./brain-machine-interfaces/)

**Research Seminar · Human-Computer Interaction · Neurotechnology**

Academic seminar work covering BMI fundamentals, signal acquisition and decoding, invasive and non-invasive approaches, application areas and ethical considerations.

## Context

These projects are included as additional academic work rather than as primary portfolio projects. My main technical projects are available directly from my GitHub profile.
