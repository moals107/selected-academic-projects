# Brain-Machine Interfaces

**Research Seminar · Human-Computer Interaction · Neurotechnology**

This project was an academic seminar on **Brain-Machine Interfaces (BMIs)** and their technical, practical and ethical implications.

## Topics Covered

- basic BMI architecture
- acquisition of neural signals
- signal interpretation and decoding
- invasive and non-invasive approaches
- communication and control applications
- medical and assistive use cases
- technical limitations
- ethical and societal questions

## Focus

The seminar was research-oriented rather than a software implementation project. The objective was to understand how brain signals can be translated into machine-readable commands and how different BMI approaches compare in terms of capability, invasiveness and practical use.

## Context

Academic seminar completed during my B.Sc. Computer Science at Heinrich Heine University Düsseldorf.
